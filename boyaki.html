ぼやきに出てきた用語

メモ

    1. ボタンを押して、今日やったことを思い出しながら話します。黙ると自動で止まります。
    2. 製品名や略語ごと文字になって、用語つきで溜まります。
    3. 溜まったら Claude に渡すと、あやふやな所を見つけて、聞き直し用の教材にしてくれます。渡さなくても、メモ帳として使えます。

    教材を読み込む

    Claude が返した JSON を貼り付けます。「聞く」の教材が、この内容に入れ替わります。

    設定

    AmiVoice

    AmiVoice API の APPKEY が必要です。キーはこの端末のブラウザにだけ保存します。「聞く」と共通です。

    止まり方

    1回のぼやきは最長3分です。

    登録する用語

    自分で足した用語、ぼやきによく出る用語の順に登録します。うまく始まらないときは数を減らしてください。
