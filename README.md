# おしえてラジオ

聞いて、後輩に説明して、覚える。資格勉強を耳と声で回すラジオです。

デモ: https://tanimoto1996.github.io/amivoice-voice-drill/

講師のミナトと後輩のヒナの掛け合いを聞いたら、今度はあなたがヒナに説明します。説明の中に大事な言葉が入っていたかを、声の聞き取り（AmiVoice API）でその場で判定し、抜けていた所はヒナが聞き返してきます。

## 1枚の流れ

1. ミナトとヒナの掛け合いを聞く（30〜60秒）。試験の場面、答え、ひっかけの順に話す。
2. ヒナ「先輩、今の、わたしに説明してもらえますか？」。ピッと鳴ってマイクが開く。
3. あなたが説明する。話しているそばから、入っていてほしい言葉（伏せてある）が当たるたびに開いていく。黙ると終わり。
4. 全部入っていれば、ヒナが喜んで次の1枚へ。抜けがあれば、ヒナが1つ聞き返す。答えられなければミナトが教えて、要点をまとめる。何も言えなければ、ミナトがかみくだいて言い直す。

「はじめる」を1回押せば、5枚ぶん（約8分）手を使わずに進みます。説明の途中で「わからない」「もう一回」と言えば、その通りに動きます。

- 前に説明できた1枚は、掛け合いを飛ばして、いきなり説明から始まります（思い出す練習）。
- 「今日の5枚」は、もう少し・まだ言えない1枚を先に、次にまだ聞いていない1枚を選びます。
- 声を出せない場所では「聞くだけ」に切り替えると、説明を頭の中でする時間をとって、ミナトが要点をまとめます。

## AmiVoice API の使いどころ

説明の判定は、話した内容に製品名が正しく文字になっているかで決まります。「EventBridge」「ValidateService」「ECS_CLUSTER」のような言葉が崩れると、言えているのに言えていない判定になります。

- **単語登録（`profileWords`）。** そのカードの掛け合いと答えに出てくる用語を先頭に、教材の用語を27語まで、接続ごとに登録します。
- **途中の結果（`resultUpdated`）で、話しているそばから判定する。** 大事な言葉が当たった瞬間にチップが開き、小さく音が鳴ります。
- **話し終わりは無音で判定。** 発話区間（`utteranceStarted` / `utteranceEnded`）と途中の結果を見て、設定した秒数（初期値3.5秒）黙ったら送信を止め、最後の結果を受け取ってから閉じます。
- **フィラーを落とす。** `keepFillerToken` を付けず、「えー」「あのー」を結果から外します。
- **ログ保存なし。** 設定で接続先を `/v1/nolog/` に切り替えられます。

APPKEY が無い端末では、ブラウザ標準の聞き取りで動きます（製品名は崩れやすくなります）。比べられるように、設定で聞き取りに使うものを切り替えられます。

## 声

サンプル教材の声は、Style-Bert-VITS2 と JVNV コーパスの音声モデル（jvnv-M1-jp をミナト、jvnv-F1-jp をヒナ）で事前に生成した音声ファイルです（`audio/aws-dop/`、284本・約26分・約10MB）。英字の製品名は、教材の読み（`terms`）でカタカナに直してから読ませています。

生成した音声は、別の音声認識（Whisper）で書き起こして台本と照らし、読み間違いを確認しています。

自分で読み込んだ教材には録音済みの声が無いため、ブラウザの読み上げで流れます（品質の高い日本語の声を優先して選びます）。

## Claude との連携

API キーは使わず、文面をコピーしてチャットに貼る方式です。

- **説明を見てもらう**：結果画面か「記録」から。カードの内容と、あなたが話した説明、言えなかった言葉を並べた依頼文がコピーされます。間違いとあやふやな所の指摘と、補足カードの作成を頼む内容です。
- **教材を作る**：「設定 → ノートから教材を作る、Claude 用の文面をコピー」。掛け合い形式の教材 JSON を作ってもらう依頼文です。返ってきた JSON をファイルに保存して「教材ファイルを読み込む」で取り込みます。

## 教材の形式

```json
{
  "title": "教材名",
  "terms": [{ "w": "EventBridge", "r": "いべんとぶりっじ" }],
  "cards": [{
    "id": "c01",
    "title": "パイプラインの失敗通知",
    "talk": [
      { "s": "h", "t": "後輩ヒナの質問" },
      { "s": "m", "t": "講師ミナトの説明" }
    ],
    "ask": "ヒナが説明を頼むひとこと",
    "keys": [{ "w": "EventBridge", "alt": ["いべんとぶりっじ"], "q": "抜けたときの聞き返し", "a": "ミナトの短い答え" }],
    "point": "要点を1文で",
    "easy": "たとえ話での言い換え",
    "scene": "", "why": "", "trap": ""
  }]
}
```

- `keys` は説明に入っていてほしい言葉です。`alt` に言い換えや読みを入れておくと、表記ゆれでも当たります。
- `talk` や `keys` の無い旧形式（`scene` / `point` / `why` / `trap` / `easy`）も読み込めます。掛け合いと判定の言葉を機械的に組み立てます。

## 制限

- 画面を消すと、話すモードでは一時停止します（マイクが止まるため）。
- 読み込んだ教材は、ブラウザの読み上げになります。
- `file://` では動きません。https か localhost で開いてください。
- APPKEY はブラウザの localStorage に保存します。自分の端末で使う前提です。
