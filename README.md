# 反射ドリル音声版（AmiVoice）

資格勉強の「反射ドリル」（引き金→即答）を、電車の中でも画面を見ずに音声だけで回すための Web アプリです。
問題文（引き金）を読み上げ、声で要点を答えると音声認識で照合し、結果と正解の要点を読み上げます。間違えた問題は優先的に再出題されます。

著者: Tempest

## 使い方

1. `index.html` を http/https で配信してスマホで開きます（下記の注意参照）
2. 画面下の「設定（APPKEY・ドリル）」を開き、AmiVoice Cloud Platform のマイページで発行した自分の APPKEY を貼って「保存」
   - APPKEY は各自で発行したものを使ってください
   - キーは端末の localStorage にのみ保存され、ファイルには含まれません
3. 「▶ 開始」をタップ
4. 画面上部の状態ラベルが「問題」になり、引き金が読み上げられます → 「どうぞ、答えてください」になったら声で要点を答えます → 「判定中」→「⭕ 正解 / △ 部分的に正解 / ❌ 不正解」が表示・読み上げられます
5. 言い直したければ「↻ もう一回」（成績は最後の結果で記録されます）、進むなら「次へ」。「■ 停止」でいつでも終了。「スキップ」は無回答（不正解）として判定に回します

画面の表示はすべてラベル付きです:「問題」「あなたの回答（認識結果）」「正解の要点」「解説（即答の全文）」。

## ドリルの取り込み

同梱のドリルはサンプル20件です。全件のドリルは各自で用意してください。

- 設定欄の「ドリルの取り込み」から JSON ファイルを選ぶと、その内容が localStorage に保存され、出題対象が切り替わります（再読み込みしても残ります）
- 「サンプルに戻す」ボタンで同梱のサンプル20件に戻せます
- 取り込むと、それまでの成績（学習記録）はリセットされます

### ドリル JSON の形式

`{trigger, answer, short}` の配列です。サンプルは `drills-sample.json` を参照してください。

```json
[
  {
    "trigger": "問題文（引き金）",
    "answer": "正解（即答の全文。画面の「解説」に表示されます）",
    "short": "声で言える要点（任意）"
  }
]
```

- `short` は任意です。**無い項目は、即答（answer）からその場で要点を自動抽出して判定します**
  - 自動抽出のルール: 最初の文をコアとし、括弧書きの補足を落とし、区切り（→ ＋ ／）ごとの節から先頭の要点を取り出す

## 判定仕様

- 判定は全文ではなく `short`（声で言える要点）のキーワードで行います。即答は平均100字超の確認用文章なので、そのまま声で答える前提にはしていません
- `short` の作り方（サンプル20件）: 即答の最初の文から、句読点・「＝」・列挙の区切りを手がかりに要点を抽出するルールで下書きを作り、全件を目視で確認・修正しました
- 正規化（全角→半角・小文字化・句読点と空白の除去）＋キーワード一致率で3段階に判定します
  - **正解**: キーワードの半分以上が一致、または3つ以上一致、など
  - **部分的に正解**: キーワードの一部（2割以上、または2つ以上）だけ言えた場合。「部分的に正解」と読み上げ、正解の要点も読み上げます
  - **不正解**: それ以外
- **部分点の扱い（仕様）**: 部分的に正解は、成績のうえでは不正解として記録し、再出題の対象にします
- 音声認識がサービス名をカタカナで返す前提で、読み替え辞書を内蔵しています（ラムダ→lambda、エスエスエム→ssm、クラウドフロント→cloudfront 等）

## 仕様メモ

- 読み上げ: ブラウザ標準の speechSynthesis（ja-JP）
- 音声認識: AmiVoice API の WebSocket リアルタイム認識。公式 JavaScript クライアントライブラリ（advanced-media-inc/amivoice-api-client-library の Wrp 版）をそのまま埋め込み、文法ファイルは `-a-general`（会話_汎用）
- 学習記録: localStorage に行ごとの出題/誤答回数を保存。次回セッションでは間違えた行が優先的に出題される
- 1問の聞き取りは最大30秒でタイムアウト（無回答は不正解扱い）

## スマホで開く際の注意

- **file:// では動きません。** マイク取得（getUserMedia）と WebSocket 接続のため、http/https で配信されたページから開く必要があります（localhost か https が確実）
- iOS Safari は読み上げ・マイクとも、最初のタップ（開始ボタン）以降でないと動かないことがあります。開始直後に無音の場合は一度停止して再開してください
- 電車内など騒音環境では認識精度が落ちます。イヤホンマイク推奨
- APPKEY には有効期限があります。期限切れの場合は AmiVoice のマイページで再発行し、設定欄に貼り直してください
