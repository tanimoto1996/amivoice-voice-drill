# あいづちラジオ

聞き流しで終わらせない、資格勉強ラジオです。
解説を1枚ずつ読み上げ、聞いた1枚について自分の言葉で「ぼやく」と、専門用語ごと文字になってその1枚に残ります。溜まったぼやきは、カードの内容と並べて Claude に渡せます。声の認識は AmiVoice API です。

デモ: https://tanimoto1996.github.io/amivoice-voice-drill/

著者: Tempest

## なぜ作り直したか

前の版は「問題を聞いて、声で答えて、キーワード一致で採点する」アウトプット用のドリルでした。まだ頭に入っていない内容は答えられず、採点も言い回しに左右されます。

こちらはインプット用です。考え方は4つです。

0. **用語を主役にする。** 資格勉強で耳から入りにくいのは、英字の製品名や略語です。聞いた用語を声で言い返し、忘れた用語を声で引き直せるようにしました。あいづち4語は語彙が小さく、どの認識でも代わりがききます。専門用語まじりの発話は、単語登録のできる AmiVoice でないと安定しません。

1. **耳で聞くための台本にする。** 矢印や記号だらけのメモは読み上げても頭に入らないので、カードを「場面 → 要点 → なぜ → ひっかけ」の話し言葉にしました。
2. **返事はあいづちだけ。** 正解を言わせません。「なるほど」「わからん」「もう一回」「メモ」の4つで、聞き流しになるのを防ぎつつ、理解度の記録が残ります。
3. **「わからん」をその場で拾う。** かみくだいた説明を続けて流し、同じ1枚を3枚あとにもう一度流します。途中で浮かんだ疑問は声でメモして、あとで生成 AI に渡せます。

## 使い方

1. スマホで開いて再生ボタンを押します。APPKEY が無くても、ボタン操作で全部使えます。
2. 声で返すときは「設定」に AmiVoice API の APPKEY を保存し、下の「声で返す」を入にします。
3. 読み上げが終わるとピッと鳴ってマイクが開きます。ボタンに書いてある言葉がそのまま言えます。

| あいづち | 言い方の例 | 起きること |
|---|---|---|
| なるほど | わかった、OK、了解、次 | 「なるほど」と記録して次の1枚へ |
| もう一回 | もっかい、もう一度 | 同じ1枚を頭から |
| わからん | わからない、どういうこと、難しい | かみくだいた説明を流し、3枚あとに再登場 |
| ぼやく | ぼやき、メモ、質問 | 続けて話した内容を、その1枚のぼやきとして保存 |
| ストップ | 止めて、休憩 | 一時停止 |

返事が無ければ、設定した秒数（初期値6秒）で「聞いた」として次へ進みます。電車では声を切って、流しっぱなしで使えます。

### ぼやく

1枚聞いたら「ぼやく」を押して（声が入なら「ぼやく」と言って）、その1枚について自分の言葉で話します。

- 6秒黙るか、「止める」を押すと保存されます（最長3分）。
- ぼやきはその1枚に紐づいて残り、カードを開くたびに表示されます。
- カードに出てくる用語のうち、ぼやきの中で言えたものが点灯します。
- 「ぼやき → Claude に渡す文面をコピー」で、カードの内容とぼやきを並べた依頼文がコピーされます。間違いとあやふやな所の指摘、補足の教材を頼む内容です。返ってきた JSON は「設定 → 教材ファイルを読み込む」で聞けます。

APPKEY が無いときは、同じ場所に手で書いて残せます。

### 要点を言い返す（任意）

設定の「要点を毎回言い返す」を入れると、声が入のとき、解説のあとに要点を言い返す時間が入ります。言えた用語が点灯し、抜けた用語は読み上げで知らせて、要点をもう一度流します。

### 用語を声で引く

あいづち待ちのあいだに用語を言うと、その説明を読み上げて、もとの1枚に戻ります。

- 「Canary って何」「Firehose のカード」「EventBridge がわからん」
- 用語だけ（「Step Functions」）でも引けます

言い返しで抜けた用語と、声で引いた用語は「一覧 → 苦手な用語」に残り、その用語が出てくるカードだけを流せます。

## AmiVoice API の使いどころ

音声認識は WebSocket インタフェース（`-a-general`）で、公式 JavaScript クライアントライブラリ（Wrp 版）を `vendor/amivoice-wrp.js` に無改変で置いています。

- **読み（`spoken`）であいづちを照合する。** 認識結果の `tokens[].spoken` はひらがなの読みなので、「もう一回／もういっかい／もう1回」の表記ゆれを気にせず辞書と突き合わせられます（`detectIntent`）。長い発話（読みで17文字以上）はあいづちとして扱いません。
- **信頼度で誤爆を防ぐ。** 発話区間の `confidence` が 0.5 未満の結果は、あいづちとして採用せず聞き直します（`CONF_MIN`）。
- **用語辞書を1つ持って、読み上げと認識の両方に使う。** 教材の `terms`（表記と読み）を、読み上げではカタカナに置き換えて発音を安定させ、認識では `profileWords`（そのセッションだけ有効な単語登録）として送ります。言い返しの窓では要点の用語だけ、あいづち待ちの窓では、いまの1枚の用語を先頭に教材の用語をまとめて送ります（最大27語。始められなかったら登録なしでやり直します）。
- **用語は表記と読みの両方で拾う。** 英字で返れば表記で、カタカナやひらがなで返れば読みで照合します。読みが4文字以下の用語（SAM、OU など）は、ふつうの言葉と紛れるので表記の一致だけを使います（`findLookup`）。
- **長いぼやきは1セッションで流す。** ぼやきは接続を1本張ったまま、発話の区切りごとの確定結果を足していきます。止めるときは送信を止めたあと、残りの結果を受け取ってから閉じます。フィラー（「えー」「あのー」）は結果から外しています。
- **聞き取り窓を短く区切る。** 読み上げ中はマイクを開かず、あいづち待ちの数秒だけ接続します。スピーカーの読み上げをマイクが拾って誤認識するのを避けるためです。AmiVoice の課金は発話区間ぶんなので、設定画面に今日使った秒数を出しています。
- **ログ保存なし。** 設定で接続先を `/v1/nolog/` に切り替えられます。声のメモには個人的な内容が入りうるためです。

## 生成 AI との連携

API キーは使わず、文面をコピーしてチャットに貼る方式です。

- **教材を作る**: 「設定 → ノートから教材を作る AI 用の文面をコピー」。耳用の書き方ルールと JSON 形式が入った依頼文です。ノートを貼り足して渡し、返ってきた JSON を保存して読み込みます。
- **ぼやきを見てもらう**: 「ぼやき → Claude に渡す文面をコピー」。ぼやいたカードと「わからん」のカードを、カードの内容つきで並べた依頼文です。間違いの指摘と補足カードを頼みます。

## 教材の形式

```json
{
  "title": "教材名",
  "terms": [
    { "w": "EventBridge", "r": "いべんとぶりっじ", "d": "イベントを受け取って次の処理へ渡す中継役です。" }
  ],
  "cards": [
    {
      "id": "c01",
      "scene": "どんな場面・要件の話か",
      "point": "覚える要点（1文）",
      "why": "なぜそうなるか（3〜4文）",
      "trap": "間違えやすい選択肢と外れる理由（任意）",
      "easy": "たとえ話での言い換え。「わからん」のときに流れる（任意）"
    }
  ]
}
```

- `terms` の `w` は本文に出てくる表記、`r` はひらがなの読み、`d` は声で引いたときに読む1文の説明（任意）です。`d` が無い用語は、その用語が出てくるカードの要点を読みます。
- 旧版の `{trigger, answer, short}` の配列も読み込めます。記号を話し言葉に機械変換するだけなので、上の AI 用の文面で書き直すほうが聞きやすくなります。
- 同梱の `deck-sample.json` は AWS DevOps Professional 向けの20枚です。

## 制限

- 読み上げはブラウザ標準の speechSynthesis です。画面を消したり別のアプリに切り替えたりすると止まります（再生中は画面が消えないようにしています）。声の質は端末によって変わります。
- `file://` では動きません。https か localhost で開いてください。
- APPKEY はブラウザの localStorage に保存します。自分の端末で使う前提です。不特定の人に配るなら、サーバー側でワンタイム APPKEY を発行する構成にしてください。
- 読み上げ中の割り込みは声ではできません。ボタンを使ってください。
