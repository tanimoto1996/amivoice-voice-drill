          設定

          声の聞き取り

          AmiVoice API の APPKEY を入れると、EventBridge や Step Functions のような製品名を、辞書つきで正確に聞き取れます。入れない場合は、ブラウザ標準の聞き取りを使います（製品名は崩れやすくなります）。キーはこの端末のブラウザにだけ保存します。
